# Introduction

ClubFund is a web-based platform designed to help university clubs manage their finances efficiently. It provides a centralized system for managing club budgets, recording income, submitting expense claims and tracking financial activities.

# Main Functions

- User Registration and Login
- Role-Based Access for Club Members and Treasurers
- Expense Claim Submission
- Receipt Uploading
- Expense Approval and Rejection
- Budget Creation and Management
- Income Recording
- Club Financial Overview
- Expense and Budget Tracking
